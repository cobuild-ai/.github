## ⚡ Quick Start

```bash
# deartalk-ai (Android)
git clone https://github.com/cobuild-ai/deartalk-ai.git
cd deartalk-ai && ./gradlew :deartalk-android:assembleDebug

# skybrain (Python / Apple Silicon)
git clone https://github.com/cobuild-ai/skybrain.git
cd skybrain && uv tool install --editable .

# continuum
git clone https://github.com/cobuild-ai/continuum.git
cd continuum && make setup
```
